## Project Description

Hackathon Project Delivery is a reusable Codex skill and plugin workflow for shipping hackathon projects end to end. It guides Codex through event research, product framing, app delivery, evidence gates, GitHub publishing, public demo deployment, final submission copy, and blocker reporting.

The project was extracted from the LaunchLens UCWS Singapore Hackathon delivery process and generalized for future UCWS, Devpost, demo-day, accelerator, university hackathon, and open-source showcase workflows. Its core principle is simple: the external review path is part of the product.

The standalone demo turns the skill into an inspectable workflow console with delivery gates, an evidence matrix, readiness scoring, and a generated Codex prompt for starting a new competition delivery run.
